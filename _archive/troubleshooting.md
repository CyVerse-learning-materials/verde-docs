# Troubleshooting Guide

This guide covers the most common issues instructors face when getting started, creating a course, and managing a course in AI-VERDE.


## Getting Started Issues

- **Can’t find the API key after creating it**  
  - OpenAI only shows the key once. If you lost it, return to the [API Keys page](https://platform.openai.com/api-keys) and generate a new one.  

- **Stache entry not accessible to the AI-VERDE team**

## Creating a Course Issues

- **Course request emailed but no response**  
  - Wait up to 48 hours for processing.  
  - Check your spam/junk folder for CyVerse messages.  

- **Some students missing from the roster**  
  - Add them yourself in the **Members** tab of your course, or  
  - Email the missing members to **ai-verde-support@cyverse.org**.

- **Course details are incorrect (name, description, or term)**  
  - Owners and instructors can edit the name, description, and dates in the **Overview** tab.  
  - Otherwise, contact **ai-verde-support@cyverse.org** with the corrections.  


## Managing a Course Issues

- **Course doesn’t show up?**
  - Confirm with support that your course was created.  
  - Check that the course status is Active and that today is between its start and end dates.  

- **A student can’t see the course?**
  - Verify they are listed under Members. If not, add them.  
  - Check the course status and dates, as above.  

- **Budget seems off or not updating**  
  - Budgets are managed by CyVerse.  
  - By default, budgets are monthly and reset on the 1st of each month, so usage drops back to zero at that point. Some courses use a different reset schedule.  
  - Instructors can view usage but not set budgets — email **ai-verde-support@cyverse.org** for adjustments.  

- **Students can’t access prompts**  
  - Prompts are shared with all course members automatically. Check that the prompt still exists in the Prompts tab and was not deleted.  
  - Check that the student is listed under Members and can see the course (see above).  

- **Error generating API keys**  
  - Retry after refreshing your dashboard session.    



## Support Contact
